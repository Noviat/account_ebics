EBICS - Batch Payments (Odoo Enterprise)

Send a payment batch to the bank from Odoo, without touching a file.

This module lets you upload an Odoo Enterprise batch payment to the bank over EBICS. You validate the batch, Odoo generates the payment file in the format the bank expects and submits it. Nothing is exported to a folder and nothing is uploaded to a portal, which also means nothing can be altered on the way.

Installation

This module depends on:

  • account_ebics (https://github.com/Noviat/account_ebics);
  • account_batch_payment (Odoo Enterprise).

Configuration

Link the bank journal to a confirmed EBICS connection (field Bank Accounts of the EBICS Configuration) holding the upload formats you use, for example pain.001 and pain.008. At upload, Odoo proposes the connection's format, the only one or the one matching the file name, and you can change it in the upload window.

Usage

Validate the batch payment, then click EBICS Upload.

Part of the EBICS suite
