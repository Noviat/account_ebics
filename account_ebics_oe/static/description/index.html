EBICS - Odoo Enterprise Integration

Glue module. Install it and forget it.

On Odoo Enterprise, this module places the EBICS Processing menu in the top bar of the Accounting application.

It is installed automatically when both of these modules are installed:

  • account_ebics;
  • account_accountant (the Odoo Enterprise Accounting application).

There is nothing to configure.

Part of the EBICS suite

This module extends EBICS Banking Protocol (account_ebics), the EBICS implementation for Odoo developed and maintained by Noviat. Install it first: https://github.com/Noviat/account_ebics

What EBICS is and what it changes, in plain language, with screen recordings of the flow: https://www.noviat.com/ebics
